# Security: untrusted content and outbound fetches

Maintainer threat model for the part of anymd that reads the open web for agents. Public behavior is in `src/content/docs/url.md` (URL rules, errors) and `src/content/docs/mcp.md` (untrusted content in tool output). The review checklist is `REVIEW.md`.

## What we protect

- **Callers' secrets:** anymd API keys, OAuth grants and sessions. Stored as SHA-256 hashes; never part of a conversion.
- **Callers' libraries:** saved documents, tags, embeddings, usage history. Every query filters by `user_id`.
- **Our infrastructure:** bindings, Worker secrets (`src/env.ts`), our own zone and anything only reachable from inside Cloudflare.
- **The agent's user:** an agent reading a page must not be steered into actions its user did not ask for.

## Threats and controls

| Threat | Control | Where |
|---|---|---|
| SSRF to private, loopback, link-local, CGNAT, multicast or own hosts, in any spelling (`2130706433`, `0x7f.1`, `[::ffff:127.0.0.1]`, `localhost.`, `x.anymd.cc`) | `normalizeTargetUrl` parses with the WHATWG URL parser, strips trailing dots and judges IP literals with the shared IANA special-purpose check | `src/convert/index.ts`, `src/lib/public-address.ts` |
| SSRF via redirect from a public page | Redirects are followed by hand (max 5); every hop passes `normalizeTargetUrl` again. A hop to another site (ignoring `www.`) also passes its opt-out, per-site rate limit and `robots.txt` | `src/convert/safe-fetch.ts`, `src/convert/web.ts` |
| Non-http schemes (`file:`, `javascript:`, `gopher:`) | Refused at input and on every redirect hop | same |
| Resource exhaustion: huge or endless bodies, slow hosts | Streamed reads with hard caps (HTML/text 5 MB, documents 20 MB, robots.txt truncated at 500 KB, images 4 MB); one 25 s deadline per fetch attempt covers all hops and the body, capped by the conversion deadline. Article images use the same `fetchPublic`; YouTube downloads only follow redirects that stay on YouTube media hosts | `readBounded` in `src/convert/provider-fetch.ts`, `fetchDeadline` |
| Prompt injection in pages, transcripts, comments, search snippets | anymd never acts on page text. MCP server instructions and the read/document tool descriptions say fetched text is untrusted data; `read_url` and `get_document` results carry `content_trust: "untrusted_third_party"`. The Markdown body stays byte-identical across channels | `src/mcp/server.ts`, `client/lib/webmcp.ts` |
| Spoofed provenance ("source: trusted-bank") | The frontmatter is generated by us first, from the URL actually fetched (final hop); titles and fields are escaped so page text cannot close the block | `formatMarkdown` in `src/convert/index.ts` |
| Script or link injection when we render saved Markdown | `renderMarkdown(md)` (untrusted mode) escapes raw HTML and drops `javascript:` links | `src/lib/markdown.ts` |
| Cross-user library or account leaks | Scopes on every route and tool; `user_id` on every library, usage, trace and vector query | `src/auth/`, `src/library/` |
| Credentials in logs | Usage rows and traces (target, error, spans, meta) replace values of credential-like query and fragment parameters, with or without a scheme, and `amd_…` keys (`redactSecrets`). Admin views redact URLs in error text and never show targets | `src/lib/usage.ts`, `src/services/admin/stats.ts` |

## Evidence

`test/untrusted-content.test.ts` covers each row above: private and self URL spellings, redirect hops to metadata/loopback/own hosts, non-http redirects and loops, cross-site redirects that hit `robots.txt`, a chunked body over 5 MB without `Content-Length`, oversized documents and text, timeouts, unsupported types, a hostile page read over MCP (injection text returned as cited data, `content_trust` set, only the page and its robots.txt fetched, no deletions, no key or secret in the result), cross-identity `get_document`/`delete_document`/`list_documents`/`search_library`, and usage-row redaction. Callback URLs for MCP Events have their own tests in `test/mcp-events.test.ts`.

## Residual risks

- **DNS rebinding.** A public hostname may resolve to a private address. A Worker cannot pin the address it checked, so we do not resolve conversion targets ourselves. `global_fetch_strictly_public` (in `wrangler.jsonc`) sends every fetch over the public internet, and Cloudflare egress cannot reach this account's private networks. Privileged sends (MCP Events callbacks) additionally resolve over DNS-over-HTTPS before each delivery (`src/events/callback-url.ts`).
- **Prompt injection is not solvable server-side.** Labels and instructions help a well-behaved client keep page text in the data channel; a client that executes tool calls because page text asks to is outside our control. What we guarantee is that anymd itself takes no action from page content, and that every write tool needs its own scope and an explicit call.
- **Provider-chosen URLs.** Social adapters fetch URLs returned by third-party APIs we chose (RapidAPI hosts). Those are not user input but are only as trustworthy as the provider.
- **Redaction is name-based.** A credential in a parameter with an innocuous name, or in a URL path segment, is stored as sent. The library keeps the full source URL on purpose, since it is the citation.
- **Library content is stored as fetched.** Saved Markdown can still contain injection text; it is labelled when served (`get_document`) but not rewritten, so search results and exports carry it verbatim.
- **Paywalls.** We send no cookies or credentials, so we only see what an anonymous visitor sees; we do not bypass paywalls. `robots.txt` and owner opt-outs are honored for every page we fetch ourselves.
